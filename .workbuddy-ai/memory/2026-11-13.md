## flutter_patcher 与本机 Flutter SDK 兼容性结论

- 本机 SDK：`/Users/zcj/D/work_zbcx/Android/env/flutter` → Flutter 3.41.6 stable / Dart 3.11.4（framework rev db50e20）。
- 仓库 flutter_patcher 当前版本 1.1.1，`pubspec.yaml` 约束：`sdk: '>=3.13.0 <4.0.0'`、`flutter: '>=3.47.0'`。
- 结论：**不兼容**。Dart 3.11.4 < 3.13.0、Flutter 3.41.6 < 3.47.0，两处都卡死，`pub get` 阶段即解析失败。
- 版本历史：v1.0.0 起就锁 Flutter 3.47；仅 v0.1.4 放宽到 `flutter >=3.3.0 / sdk >=3.0.0`，但那是 Android-only 早期版本（CLI 叫 `pack`、无 iOS 支持）。
- 支持区间是 3.47.0 – 3.47.9，连 3.48 都不在范围内 —— 因为 patch 本质是替换 libapp.so 的 AOT 快照，与引擎/快照格式强绑定，跨小版本不可靠。
- 待用户决策：升 Flutter 到 3.47.x / 留在 3.41 放弃 v1.x / fork 自行适配。
